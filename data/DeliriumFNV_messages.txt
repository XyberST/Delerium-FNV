DeliriumFNV: ragdoll messages you can use in DeliriumFNV_reactions.txt
==============================================================================

Every message the Delirium engine understands and the parameters each takes.
Kinds: float = number, int = whole number, bool = true/false, vec3 = x,y,z (three numbers joined by commas), text = a word such as fb or lb.
Names are not case sensitive in the script file. A parameter you leave out keeps the engine's own default. Parameters marked (unused) are accepted by the engine but do nothing.

Every message also takes start (bool): true switches its behaviour on, false switches it off again.
Macros (the built-in reactions, tuned by the [Reactions] keys of the ini): @windmill @writhe @writheupper @pedal @curl @rollup @explosion @highfall @catchfall @stop
